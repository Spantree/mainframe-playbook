## Getting Started

This documentation site was scaffolded with [Trellis](https://github.com/spantree/trellis).

### Project Structure

```
packages/
├── docs/      # This Docusaurus site
├── slides/    # Slidev presentation
└── landing/   # Landing page
```

### Development

```bash
# Start the docs dev server
bun run dev:docs

# Start the slides dev server
bun run dev:slides

# Build everything
bun run build
```
